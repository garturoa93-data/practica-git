# Práctica Git

Repositorio de práctica del curso de Git: semana 1 (fundamentos) y semana 2 (ramas, merges, .gitignore y cómo deshacer cambios).

## Contenido

- `plan.md`: temas de cada semana.
- `comandos.md`: comandos que voy practicando.
- `glosario.md`: términos básicos de Git.
- `.gitignore`: archivos que Git no debe rastrear (cache de Python, entorno virtual, `.env`, logs y configuración del editor).
