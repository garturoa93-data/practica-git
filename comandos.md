# Comandos practicados

- `git init`: crea un repositorio nuevo.
- `git status`: muestra el estado de los archivos.
- `git add`: prepara cambios para el commit.
- `git commit`: guarda los cambios preparados.
- `git diff`: muestra cambios aún no preparados.
- `git log --oneline`: historial resumido.

## Ramas (Semana 2)

- `git branch`: lista las ramas locales; con un nombre, crea una rama nueva.
- `git checkout -b <rama>`: crea una rama y se cambia a ella.
- `git switch <rama>`: se cambia a una rama existente.
